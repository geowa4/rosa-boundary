# PART A — Provisioning and discovery

## A1. Scope & boundaries

In scope (runtime only):

- The `create-investigation` Lambda end to end: request parsing, `skip_task`, input validation, existing-task handover ("duplicate detection"), EFS access-point create-or-reuse, per-investigation task-definition registration, `RunTask`, explicit `TagResource`, deadline computation, EMF metric emission, response schema, error paths ([H#L79-L316](https://github.com/geowa4/rosa-boundary/blob/509078b/lambda/create-investigation/handler.py#L79-L316), [H#L460-L1098](https://github.com/geowa4/rosa-boundary/blob/509078b/lambda/create-investigation/handler.py#L460-L1098)).
- CLI provisioning/discovery: `start-task`, `create-investigation`, `list-tasks`, `list-investigations`, and the DescribeTasks/wait-for-RUNNING portion of `join-task` ([start_task.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/cmd/start_task.go), [create_investigation.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/cmd/create_investigation.go), [list_tasks.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/cmd/list_tasks.go), [list_investigations.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/cmd/list_investigations.go), [join_task.go#L98-L124](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/cmd/join_task.go#L98-L124)); the AWS wrappers [internal/aws/ecs.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/aws/ecs.go), [internal/aws/efs.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/aws/efs.go); the Lambda client [internal/lambda/client.go](https://github.com/geowa4/rosa-boundary/blob/509078b/internal/lambda/client.go).
- Static preconditions (described, not traced): [lambda-create-investigation.tf](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/lambda-create-investigation.tf), [ecs.tf](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/ecs.tf), [efs.tf](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/efs.tf), [outputs.tf](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/outputs.tf), Lambda IAM policies in [iam.tf#L272-L305](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/iam.tf#L272-L305), role identities in [account-iam.tf#L10-L30](https://github.com/geowa4/rosa-boundary/blob/509078b/deploy/regional/account-iam.tf#L10-L30).

Out of scope (other agents): OIDC token validation internals beyond the branch points that affect provisioning; the ECS Exec/SSM session itself; what the container does after launch (entrypoint, S3 sync); Terraform apply, CI, image builds.
