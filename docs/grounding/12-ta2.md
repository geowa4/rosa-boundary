### T4 — AWS API reach (`awsapi` package) — summary of what can be touched

The server reaches AWS in exactly two ways: (a) the **customer cluster's account** through the backplane-cli credential chain (T2 AWS path) — read-only for `aws-get`, EC2 `RebootInstances`/`TerminateInstances` for the two writes when enabled; (b) **its own account** only implicitly: CloudWatch Logs via the awslogs driver (execution role), Secrets Manager at task start (execution role), S3 `config.yaml` read by the sidecar (task role). The task role's S3 `PutObject` and `cloudwatch:PutMetricData` grants are **unused by code**. There is **no** STS/IAM call in TA code against its own account.
