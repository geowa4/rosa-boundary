## A.10 Open questions / verification gaps (Part A)

1. **`OC_VERSION` is dead at this commit.** Image ships one `oc` (4.22.18) at `/usr/local/bin/oc`; entrypoint looks for `/opt/openshift/${OC_VERSION}/oc`. README, skel CLAUDE.md, overview.md claim 4.14–4.20 switching. Settle: run `OC_VERSION=4.20 /usr/local/bin/entrypoint.sh oc version --client` in the image and confirm the warning + 4.22 output. (https://github.com/geowa4/rosa-boundary/blob/509078b/skel/sre/.claude/CLAUDE.md#L17-L33 ; https://github.com/geowa4/rosa-boundary/blob/509078b/docs/architecture/overview.md#L140)
2. **ECS Exec shell environment.** Exec shells receive the task-definition environment, not the entrypoint's exported `AWS_REGION`/`CLAUDE_CODE_USE_BEDROCK`. Does `claude` in an exec shell find a region (via `AWS_REGION` absent → SDK default chain / `AWS_DEFAULT_REGION`)? UNVERIFIED; settle with `env | grep AWS` inside a live session.
3. **`curl` in the final image.** Entrypoint and sidecar health check rely on `curl`; the final stage does not install it explicitly (UBI9 base ships `curl-minimal`). Settle: `podman run --rm <image> command -v curl`.
4. **sudo breadth.** `sre ALL=(ALL) NOPASSWD: ALL` lets an SRE become root, edit/kill the entrypoint (defeating exit sync), or read the kube-proxy's `/tmp/kubeconfig` via `nsenter`/`--container kube-proxy`. Already flagged in `docs/adversary-findings_20260702.json`. Is this accepted risk? (https://github.com/geowa4/rosa-boundary/blob/509078b/Containerfile#L247-L251)
5. **Task role is the only AWS identity in the container.** Any SRE can `aws s3 cp` arbitrary objects anywhere in the audit bucket (PutObject `/*`), including into another investigation's prefix (no `s3:prefix` condition, Object Lock makes such writes permanent). Settle: confirm intent; consider prefix-conditioned policy or object tagging.
6. **Secrets Manager kubeconfig provisioning** (`rosa-boundary/clusters/<cluster_id>/kubeconfig`) is not created by any root in this repo. Who writes it, and does an SRE-selected `--cluster-id` pick an arbitrary existing secret? UNVERIFIED.
7. **Default exec command drift**: overview.md says `runuser -u sre -- bash`; code is `runuser -u sre -- sh -c 'cd ~ && exec bash --login'` (https://github.com/geowa4/rosa-boundary/blob/509078b/docs/architecture/overview.md#L221).
8. **VPC endpoints drift**: overview.md lists ssmmessages/kms/logs/ecr/ecs interface endpoints; none exist. SSM, KMS, Logs, ECR, STS traffic traverses NAT. (https://github.com/geowa4/rosa-boundary/blob/509078b/docs/architecture/overview.md#L146 ; #L220)
9. **AWS CLI path drift** in skel CLAUDE.md (`/opt/aws-cli-official/v2/current/bin/aws`) vs image (`/usr/local/aws-cli/v2/current/aws` via alternatives) (https://github.com/geowa4/rosa-boundary/blob/509078b/skel/sre/.claude/CLAUDE.md#L15 ; https://github.com/geowa4/rosa-boundary/blob/509078b/Containerfile#L237).
10. **OCM token not revoked** on `clear` or task stop; only the local copy is removed. Expected SSO access-token lifetime (~15 min) is the real bound. UNVERIFIED with SSO config.
